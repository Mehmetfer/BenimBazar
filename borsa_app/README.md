# Borsa App (Flutter)

Kağıt üstü **Al / Sat** mobil uygulaması.

## Çalıştır

```bash
export PATH="/opt/flutter/bin:$PATH"
cd borsa_app
flutter pub get
flutter run -d chrome --web-port 8080
# veya Android cihaz/emülatör:
flutter run
```

## Özellikler

- BIST benzeri simüle fiyatlar
- Al / Sat emirleri
- Portföy, nakit, K/Z
- Son işlemler
- Başlangıç bakiyesi: 100.000 TL
